# B2 verification: applications, Standards Runner and evidence

What was run to verify the second feature set (invitations, the applicant area, the Standards
Runner, the document library, reading on the AI model, prefill with citations, review and submit,
applicant isolation), what each step showed, what was fixed on the way, and the limits that remain.
Every result below was observed on a database rebuilt from nothing for this run, on 2026-11-17.
Screenshots are in [`b2-2026-11/`](b2-2026-11/); they show only generic sample data. The per-task
screenshots taken while the feature set was built (`task4-*.png` … `task11-*.png`) are in the same
folder and are referenced where they show something this run did not repeat.

**Instance.** MemberJunction `v6.2.2` linked with BizApps Common `v5.66.0`, Tasks `1.13.0`,
Committees `1.5.0` and this repository (`feature/b2-applications`); SQL Server in Docker; MJAPI on
port 4050, MJExplorer on 4251; Node 24; the evidence store is the development local-disk driver
(`pnpm run dev:storage`); scan recognition and evidence reading on Gemini 3.8 Flash through MJ's AI
prompts. Setup and procedures: [`docs/dev-instance.md`](../dev-instance.md). Nobody signed in by
hand: staff by `POST /auth/dev-login` (`pnpm run persona <name>`), applicants by magic links (the
invitation links the wizard printed, and `pnpm run persona applicant-b`).

**Browser.** The chrome-devtools tool could not start in this session (its Chrome profile was held by
another session's browser, which was left alone), so every browser step was driven by a scripted
headless Chrome (Puppeteer 25, the copy in the workspace) with one isolated browser context per
persona. Screenshots, accessibility snapshots, console messages and network checks came from it.

## Limits (known, not defects of this run)

- A scan over 100 pages or 18 MB is stored and hashed but not read; the library says so.
- A text-layer PDF's citations carry no page number: MJ's `ParsePdf` returns the document's text as
  one string, so the reader sees no page markers (scans do: `[Page N]`). Citations locate by verbatim
  excerpt and character span, and the viewer highlights the span.
- A magic link works once and a session lasts 8 hours, so a returning applicant needs a new link
  from staff (`Send a new link`) until the platform offers self-service re-issue.
- Prefill of a 150-standard application holds the application lock about 3 s, most of it MJ's
  per-save change-history writes (`docs/dev-instance.md`, "Prefill resolution").
- `Host Query` sources and the Data Bindings screen are not built (planned separately).
- `Read again` is offered to applicants only; staff cannot requeue a document.
- Confirmed answers show the confirmer's email address, not a display name.
- An answer whose drafted text is kept but given a self-assessment is saved as the applicant's
  (`AuthorType Human`); its citation stays.
